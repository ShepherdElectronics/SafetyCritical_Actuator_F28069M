## Versioning convention

This archive uses industry-style pre-release semantic version labels:

- `v0.1` = earliest packaged baseline in this archive
- `v0.2` through `v0.8` = incremental generated versions from today's SDC2 code/test-environment work
- Each package keeps a descriptive suffix after the version for traceability
